The original requirement:

We need to support project-linked contribution workbooks for discovery and delivery input.

The system must allow internal Muloo operators to:
1. Create project workbooks linked to a project.
2. Select a workbook/resource type, for example:
   - HubSpot discovery
   - Website discovery
   - Operations discovery
   - Tech stack/current tools
   - Product lines/services
   - Business process/current operations
   - General project resources
3. Pull reusable discovery questions from a question library into a project-specific workbook.
4. Customise workbook questions per project.
5. Assign workbook questions or sections to specific contributors.
6. Add project resources such as a Miro board link.
7. See a readiness/progress summary for the project workbooks.
8. Support Magnisol seed data as a realistic test case.

The system must allow the client/project champion to:
1. Access the client portal project workspace.
2. See project workbooks assigned or visible to them.
3. Add required contributors from inside the client portal.
4. Assign or involve contributors without giving them full client portal access.
5. Allow verified stakeholders/contributors to provide answers, documents, links, or supporting information.
6. Restrict access so contributors only see the workbook/questions/resources they are assigned to.
7. Prevent contributors from viewing unrelated project data.
8. Prevent non-champions from creating contributors.
9. Prevent unauthorised users from accessing client workbook routes.
